# Dazul Insight AI v4

## Recursos

- Busca inteligente na pasta S:\
- Electron funcionando corretamente
- Backend automático
- Inicialização com 1 clique
- Pesquisa funcionando
- Resposta por IA local via Ollama
- CMD não fecha sozinho

## COMO USAR

1. Extraia o ZIP
2. Inicie o Ollama localmente (exemplo: `ollama serve`)
3. Baixe um modelo (exemplo: `ollama pull llama3.1`)
4. Clique duas vezes em INICIAR.bat
5. Aguarde instalar dependências
6. O sistema abrirá automaticamente

## CONFIGURAÇÃO OLLAMA (OPCIONAL)

Você pode configurar via variáveis de ambiente:

- `OLLAMA_URL` (padrão: `http://127.0.0.1:11434/api/generate`)
- `OLLAMA_MODEL` (padrão: `llama3.1`)

## IMPORTANTE

Necessário Node.js instalado:
